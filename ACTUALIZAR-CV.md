# CV actualizado con la fuente de 2026

La información profesional de `cv.html`, el PDF en `output/pdf/` y la trayectoria del portfolio se actualizaron con el CV aportado en noviembre de 2026. La formación y los sitios publicados conservan datos existentes del repositorio.

Se corrigió el rol de GYL Group a .NET / Xamarin, se especificó Flutter y Dart en Dicsys y se incorporaron INTI, docencia de IA, Cropbase y automatizaciones. Cropbase se presenta como iniciativa en desarrollo y las automatizaciones como proyectos y prototipos.

## Datos que todavía podrían mejorar la candidatura

- Elegir el puesto principal para cada postulación: Mobile, Full Stack o integración de IA y automatización.
- Agregar resultados verificables por experiencia: alcance, funcionalidades entregadas, usuarios o mejoras medibles.
- Confirmar el nivel de inglés y la modalidad de trabajo buscada.
- Incorporar demostraciones o repositorios públicos de Cropbase y automatizaciones cuando estén disponibles.
- Precisar qué partes de las iniciativas de IA están implementadas y cuáles siguen en diseño.

No se agregaron métricas, seniority ni fechas laborales nuevas. El PDF conserva texto seleccionable, enlaces de contacto y estructura de una columna.

## Archivos

- `output/pdf/Javier_Gimenez_CV_2026.pdf`: CV de una página para compartir.
- `cv.html`: versión web con descarga directa y opción de impresión.
- `build_cv.py`: fuente para regenerar el CV web y PDF con ReportLab y validar el PDF con pypdf/pypdfium2.

Para imprimir desde la web, usar A4 y desactivar encabezados y pies del navegador. El PDF generado directamente ya tiene su propia composición.
